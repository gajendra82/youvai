# OAuth Client Setup Guide - Fix Authorization Error

## Problem
You're getting this error:
```
Access blocked: authorisation error
The OAuth client was not found.
If you are a developer of this app, see error details.
Error 401: invalid_client
```

This means the OAuth client ID is not properly configured in Google Cloud Console.

## Solution

### Step 1: Go to Google Cloud Console

1. **Visit Google Cloud Console**
   - Go to: https://console.cloud.google.com/
   - Select your project: `youvai-56995`

### Step 2: Navigate to OAuth 2.0 Client IDs

1. **Go to APIs & Services**
   - Click on "APIs & Services" in the left sidebar
   - Click on "Credentials"

2. **Find or Create OAuth 2.0 Client ID**
   - Look for existing OAuth 2.0 Client IDs
   - If you don't see one for web, click "Create Credentials" → "OAuth 2.0 Client IDs"

### Step 3: Configure Web Application OAuth Client

1. **Application Type**: Select "Web application"

2. **Name**: Give it a name like "YouVai Web Client"

3. **Authorized JavaScript origins**:
   ```
   https://aesthetic.youv.ai
   http://localhost:3000
   http://localhost:8080
   ```

4. **Authorized redirect URIs**:
   ```
   https://aesthetic.youv.ai/__/auth/handler
   http://localhost:3000/__/auth/handler
   http://localhost:8080/__/auth/handler
   ```

5. **Click "Create"**

### Step 4: Copy the Client ID

1. **Copy the generated Client ID**
   - It should look like: `53452910725-6vf2o2pbhjaktliko9ertg454alob398.apps.googleusercontent.com`
   - This is the correct client ID we're now using

### Step 5: Verify Firebase Console Configuration

1. **Go to Firebase Console**
   - Visit: https://console.firebase.google.com/
   - Select your project: `youvai-56995`

2. **Authentication Settings**
   - Go to Authentication → Sign-in method
   - Click on "Google" provider
   - Make sure it's enabled
   - Add your domain to "Authorized domains":
     - `aesthetic.youv.ai`

## Common Issues and Solutions

### Issue 1: "OAuth client was not found"
**Solution**: 
- Verify the client ID is correct in Google Cloud Console
- Make sure the client ID matches exactly in your code
- Check that the OAuth client is for "Web application" type

### Issue 2: "Unauthorized JavaScript origin"
**Solution**:
- Add your domain to "Authorized JavaScript origins" in Google Cloud Console
- Make sure the protocol (http/https) matches exactly

### Issue 3: "Unauthorized redirect URI"
**Solution**:
- Add the correct redirect URI to "Authorized redirect URIs"
- The format should be: `https://yourdomain.com/__/auth/handler`

### Issue 4: "Access blocked: authorization error"
**Solution**:
- Check that Google Sign-In is enabled in Firebase Console
- Verify your domain is in the authorized domains list
- Make sure the OAuth client is properly configured

## Important Notes

1. **Client ID Format**: Must be exactly as generated by Google Cloud Console
2. **Domain Matching**: JavaScript origins must match your actual domain exactly
3. **Protocol**: Use `https://` for production, `http://` for localhost
4. **Redirect URIs**: Must include the `/__/auth/handler` path
5. **Firebase Integration**: OAuth client must be linked to your Firebase project
